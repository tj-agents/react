# React capability architecture

The repository owns one host-neutral React and TypeScript scope. Each public skill is a complete canonical
definition under `.agents/contract`; selection metadata separates the framework core from optional libraries and
repository shapes. Host discovery entries are generated references, and the generated `plugins/react` tree carries
full bodies so installations never depend on files outside the package.

The Codex manifest is semantic-versioned. Claude intentionally omits a version and remains commit-versioned until
the ecosystem catalog and release work establishes the shared publication contract in P5.
